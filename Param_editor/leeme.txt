=============================================
PARAM_EDITOR v2.0
=============================================

OBJETIVO
--------
Editar en Excel lotes de parámetros contenidos en carpetas llamadas "factory" y reconstruirlos sin alterar información que el usuario no haya modificado.

La aplicación trabaja únicamente dentro de la carpeta local "para_procesar".

FLUJO
-----
1. Copia una o varias familias de parámetros dentro de:

   para_procesar/

   Se admiten, entre otras, estas dos estructuras:

   para_procesar/MAQUINA/factory/MATERIAL/...
   para_procesar/MAQUINA/PARAMS_LASER/factory/MATERIAL/...

2. Ejecuta PARAMtoEXCEL.exe (o "python main.py").

3. Se genera un "parametros.xlsx" dentro de cada carpeta factory encontrada.

4. Edita únicamente los valores de parámetros Nxxx que necesites.

5. Ejecuta EXCELtoPARAM.exe (o "python excel_to_param.py").

6. Los resultados se generan en:

   parametros_exportados/

   manteniendo la jerarquía de máquina / factory / material.

SEGURIDAD DEL ROUND-TRIP
------------------------
- El Excel contiene una hoja interna oculta (_SOURCE) con la fuente original.
- Si no se modifica ninguna celda, el contenido del parámetro reconstruido es byte a byte igual al original.
- Se conserva el carácter R/S real de cada línea original.
- Se conserva el orden de líneas, comentarios, líneas no reconocidas, decimales y saltos de línea.
- Los parámetros repetidos aparecen como Nxxx, Nxxx#2, Nxxx#3, etc.
- Una celda vacía de un parámetro que no existía no crea una línea nueva.
- Una celda existente que se vacía genera deliberadamente NxxxR/S sin valor.

COLUMNAS DE CONTROL
-------------------
N000               Ruta relativa de factory. No modificar.
__subcarpeta        Material/subcarpeta original. No modificar.
__archivo_origen    Nombre original. No modificar.
__archivo_salida    Nombre del .lparam de salida. Puede modificarse.
__id                Identificador interno oculto. No modificar.

La modificación de campos de control distintos de __archivo_salida aborta la exportación.

COLISIONES
----------
Antes de escribir un solo LPARAM, EXCELtoPARAM valida todos los destinos.
Si dos recetas producirían el mismo nombre (también considerando mayúsculas/minúsculas de Windows), se aborta toda la exportación y se muestran los orígenes en conflicto.

VALIDACIONES
------------
Las validaciones se aplican a celdas modificadas, no a parámetros históricos sin tocar.
Actualmente se comprueba:
- tipos y límites definidos en methadata.xlsx cuando existan;
- N004 (espesor) numérico y > 0 cuando se modifica;
- N005 (potencia) numérico y no negativo cuando se modifica;
- duty entre 0 y 100 cuando la metadata lo identifica.

Al finalizar se crea parametros_exportados/manifest.csv con el origen, destino y columnas modificadas.

METADATA
--------
La aplicación lee todas las hojas de modulos/methadata.xlsx. No depende de nombres de hoja fijos, por lo que "FOCALES" se procesa correctamente.

COMPILACION EN WINDOWS
----------------------
Desde la carpeta Param_editor:

  pyinstaller PARAMtoEXCEL.spec
  pyinstaller EXCELtoPARAM.spec

Los .spec incluyen modulos/methadata.xlsx dentro del ejecutable.

DEPENDENCIAS DE DESARROLLO
--------------------------
- Python 3.11+
- openpyxl
- pyinstaller (solo para generar los EXE)

TESTS
-----
Desde Param_editor:

  python -m unittest discover -s tests -v

Los tests cubren round-trip exacto, edición de un único parámetro, R/S, parámetros repetidos, búsqueda recursiva de factory, validaciones, protección de rutas y colisiones.
